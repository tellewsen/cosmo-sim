# Hydrodynamics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Eulerian gas hydrodynamics to RUSTIS behind `--features hydro` to reproduce Ellewsen, Falck & Mota (2018) stacked halo profiles for ΛCDM and four Symmetron variants with three baryonic physics tiers.

**Architecture:** Domain-grid Godunov hydro (Option A from design spec). Gas state (ρ, v, u) lives in `SimScratch` as flat n³ arrays alongside the existing gravity arrays. The Godunov step is operator-split from gravity, expansion, and baryonic physics sub-steps and wired into the simulation loop after the gravitational kick.

**Tech Stack:** Rust, `rayon` for data-parallelism, existing `SimScratch`/`Simulation` infrastructure. No new external crates.

**Reference:** `docs/specs/2026-04-11-hydro-design.md`, Ellewsen et al. 2018 (arXiv:1803.04197), RAMSES paper (Teyssier 2002).

## Unit conventions (read before writing any code)

Throughout this feature, code units are:
- **Length:** Mpc/h (comoving)
- **Velocity / sound speed:** km/s (peculiar, not supercomoving)
- **Time:** supercomoving conformal time τ (same as DM leapfrog)
- **gas_rho:** comoving gas density in units of ρ̄_matter (dimensionless; mean ≈ Ω_b/Ω_m ≈ 0.167)
- **gas_u:** specific internal energy (km/s)²
- **Pressure:** P = (γ−1) × gas_rho × gas_u  [same units as gas_rho × (km/s)²]
- **Sound speed:** c_s = √(γ (γ−1) gas_u)  [km/s]
- **Temperature:** T = (μ m_p / k_B) × gas_u, with μ=0.59 (ionised primordial gas), m_p=938.3 MeV/c²

Pressure gradient force: ∂P/∂x has units (km/s)²/(Mpc/h) — same as gravitational acceleration from `scratch.grav`, so they add directly.

```rust
//! HLL Riemann solver for the Euler equations.
//!
//! Computes intercell flux F(U_L, U_R) in the x-direction.
//! U = [ρ, ρvx, ρvy, ρvz, E],  E = ρu + ½ρ|v|²,  P = (γ-1)(E - ½ρ|v|²).

/// MinMod slope limiter: returns 0 if slopes have opposite signs,
/// otherwise the smaller-magnitude slope.
pub fn minmod(a: f64, b: f64) -> f64 {
    if a * b <= 0.0 { 0.0 }
    else if a.abs() <= b.abs() { a }
    else { b }
}

/// Pressure from conserved variables.
#[inline]
pub fn pressure(u: &[f64; 5], gamma: f64) -> f64 {
    let rho = u[0];
    let vx  = u[1] / rho;
    let vy  = u[2] / rho;
    let vz  = u[3] / rho;
    (gamma - 1.0) * (u[4] - 0.5 * rho * (vx*vx + vy*vy + vz*vz))
}

/// Physical flux in the x-direction: F = [ρvx, ρvx²+P, ρvxvy, ρvxvz, (E+P)vx].
pub fn flux_x(u: &[f64; 5], gamma: f64) -> [f64; 5] {
    let rho = u[0];
    let vx  = u[1] / rho;
    let vy  = u[2] / rho;
    let vz  = u[3] / rho;
    let p   = pressure(u, gamma);
    [
        rho * vx,
        rho * vx * vx + p,
        rho * vx * vy,
        rho * vx * vz,
        (u[4] + p) * vx,
    ]
}

/// HLL wave speed estimates (Einfeldt, 1988).
/// Returns (S_L, S_R): left and right signal speeds.
pub fn hll_speeds(u_l: &[f64; 5], u_r: &[f64; 5], gamma: f64) -> (f64, f64) {
    let rho_l = u_l[0]; let vx_l = u_l[1] / rho_l;
    let rho_r = u_r[0]; let vx_r = u_r[1] / rho_r;
    let p_l = pressure(u_l, gamma).max(0.0);
    let p_r = pressure(u_r, gamma).max(0.0);
    let cs_l = (gamma * p_l / rho_l).sqrt();
    let cs_r = (gamma * p_r / rho_r).sqrt();
    let s_l = (vx_l - cs_l).min(vx_r - cs_r);
    let s_r = (vx_l + cs_l).max(vx_r + cs_r);
    (s_l, s_r)
}

/// HLL intercell flux at the interface between left state U_L and right state U_R.
pub fn hll_flux(u_l: &[f64; 5], u_r: &[f64; 5], gamma: f64) -> [f64; 5] {
    let (s_l, s_r) = hll_speeds(u_l, u_r, gamma);
    if s_l >= 0.0 { return flux_x(u_l, gamma); }
    if s_r <= 0.0 { return flux_x(u_r, gamma); }
    let f_l = flux_x(u_l, gamma);
    let f_r = flux_x(u_r, gamma);
    let mut f = [0.0f64; 5];
    for i in 0..5 {
        f[i] = (s_r * f_l[i] - s_l * f_r[i] + s_l * s_r * (u_r[i] - u_l[i]))
               / (s_r - s_l);
    }
    f
}
```

## Task 4: MUSCL-Hancock Godunov sweep (1D, x-direction)

**Files:**
- Create: `src/hydro/solver.rs`

The Godunov solver operates on conserved variables. For each sweep direction, it:
1. Reconstructs primitive variable slopes using MinMod
2. Predicts half-step interface states (Hancock predictor)
3. Solves Riemann problem at each interface
4. Updates conserved variables from net fluxes

Primitive variables: W = [ρ, vx, vy, vz, P]. Conserved: U = [ρ, ρvx, ρvy, ρvz, E].

- [ ] **Create `src/hydro/solver.rs` with conversion helpers and 1D sweep**

```rust
//! MUSCL-Hancock Godunov hydro solver.
//!
//! Operates on the flat n³ gas arrays from `SimScratch`.
//! Each axis is swept independently (Strang splitting is not applied —
//! the simple Lie-Trotter splitting is sufficient for first implementation).

use crate::hydro::riemann::{hll_flux, minmod, pressure};

const GAMMA: f64 = 5.0 / 3.0;

// ── Primitive ↔ Conserved conversions ────────────────────────────────────────

/// Primitive W = [ρ, vx, vy, vz, P]  →  Conserved U = [ρ, ρvx, ρvy, ρvz, E].
#[inline]
pub fn prim_to_cons(w: &[f64; 5], gamma: f64) -> [f64; 5] {
    let e = w[4] / (gamma - 1.0)
          + 0.5 * w[0] * (w[1]*w[1] + w[2]*w[2] + w[3]*w[3]);
    [w[0], w[0]*w[1], w[0]*w[2], w[0]*w[3], e]
}

/// Conserved U  →  Primitive W.
#[inline]
pub fn cons_to_prim(u: &[f64; 5], gamma: f64) -> [f64; 5] {
    let rho = u[0].max(1e-30);
    let vx  = u[1] / rho;
    let vy  = u[2] / rho;
    let vz  = u[3] / rho;
    let p   = pressure(u, gamma).max(1e-30 * rho);
    [rho, vx, vy, vz, p]
}

// ── Hancock half-step predictor ───────────────────────────────────────────────

/// Given primitive W and reconstructed slopes dW/dx, predict the half-step
/// evolution in the x-direction over Δt/2.
///
/// Euler equations in primitive form (x-sweep only):
///   ∂ρ/∂t  = −vx ∂ρ/∂x  − ρ ∂vx/∂x
///   ∂vx/∂t = −vx ∂vx/∂x − (1/ρ) ∂P/∂x
///   ∂vy/∂t = −vx ∂vy/∂x
///   ∂vz/∂t = −vx ∂vz/∂x
///   ∂P/∂t  = −γP ∂vx/∂x − vx ∂P/∂x
pub fn hancock_predict_x(w: &[f64; 5], dw: &[f64; 5], dt_half_over_dx: f64) -> [f64; 5] {
    let [rho, vx, vy, vz, p] = *w;
    let [drho, dvx, dvy, dvz, dp] = *dw;
    let c = dt_half_over_dx; // Δt/(2Δx)
    [
        rho - c * (vx * drho + rho * dvx),
        vx  - c * (vx * dvx + dp / rho),
        vy  - c * (vx * dvy),
        vz  - c * (vx * dvz),
        p   - c * (GAMMA * p * dvx + vx * dp),
    ]
}

// ── 1D x-sweep ────────────────────────────────────────────────────────────────

/// Apply one Godunov sweep in the x-direction to the full n³ grid.
///
/// `gas_rho`, `gas_vel`, `gas_u` are flat C-order arrays of length n³.
/// `dx` is cell width [Mpc/h], `dt` is timestep [supercomoving τ].
/// `n` is the grid size per side.
///
/// Periodic boundary conditions.
pub fn sweep_x(
    gas_rho: &mut [f64],
    gas_vel: &mut [[f64; 3]],
    gas_u:   &mut [f64],
    dx: f64,
    dt: f64,
    n:  usize,
    gamma: f64,
) {
    let n2 = n * n;
    // Scratch: one conserved-variable array per cell
    let mut u_old: Vec<[f64; 5]> = (0..n*n*n).map(|idx| {
        let w = [gas_rho[idx], gas_vel[idx][0], gas_vel[idx][1],
                 gas_vel[idx][2], (gamma - 1.0) * gas_rho[idx] * gas_u[idx]];
        prim_to_cons(&w, gamma)
    }).collect();

    let mut u_new = u_old.clone();
    let dtdx  = dt / dx;
    let dt2dx = 0.5 * dtdx;

    // For each (j,k) column, sweep along i (x-axis)
    for j in 0..n {
        for k in 0..n {
            let col: Vec<[f64; 5]> = (0..n)
                .map(|i| u_old[i * n2 + j * n + k])
                .collect();

            // Convert column to primitive
            let wc: Vec<[f64; 5]> = col.iter()
                .map(|u| cons_to_prim(u, gamma))
                .collect();

            // Compute MinMod slopes
            let slopes: Vec<[f64; 5]> = (0..n).map(|i| {
                let il = if i == 0 { n - 1 } else { i - 1 };
                let ir = if i == n - 1 { 0 } else { i + 1 };
                let mut s = [0.0f64; 5];
                for q in 0..5 {
                    s[q] = minmod(wc[i][q] - wc[il][q], wc[ir][q] - wc[i][q]);
                }
                s
            }).collect();

            // Compute interface fluxes
            for i in 0..n {
                let ir = if i == n - 1 { 0 } else { i + 1 };

                // Hancock half-step on left and right cells
                let w_l = hancock_predict_x(&wc[i],  &slopes[i],  dt2dx);
                let w_r = hancock_predict_x(&wc[ir], &slopes[ir], dt2dx);

                // Right interface state of cell i: W_i + ½slope
                // Left  interface state of cell ir: W_ir − ½slope
                let mut if_l = [0.0f64; 5];
                let mut if_r = [0.0f64; 5];
                for q in 0..5 {
                    if_l[q] = w_l[q] + 0.5 * slopes[i][q];
                    if_r[q] = w_r[q] - 0.5 * slopes[ir][q];
                }

                // Floor densities and pressures
                if_l[0] = if_l[0].max(1e-30);
                if_r[0] = if_r[0].max(1e-30);
                if_l[4] = if_l[4].max(1e-30);
                if_r[4] = if_r[4].max(1e-30);

                let u_if_l = prim_to_cons(&if_l, gamma);
                let u_if_r = prim_to_cons(&if_r, gamma);
                let flux = hll_flux(&u_if_l, &u_if_r, gamma);

                // Update: cell i loses flux, cell ir gains flux
                for q in 0..5 {
                    u_new[i  * n2 + j * n + k][q] -= dtdx * flux[q];
                    u_new[ir * n2 + j * n + k][q] += dtdx * flux[q];
                }
            }
        }
    }

    // Write back
    for idx in 0..n*n*n {
        let w = cons_to_prim(&u_new[idx], gamma);
        gas_rho[idx]    = w[0].max(1e-30);
        gas_vel[idx][0] = w[1];
        gas_vel[idx][1] = w[2];
        gas_vel[idx][2] = w[3];
        gas_u[idx]      = (w[4] / ((gamma - 1.0) * w[0])).max(1e-30);
    }
}
```

```rust
/// Transpose gas arrays to bring axis `ax` into the x-position,
/// call sweep_x, then transpose back.
pub fn sweep_axis(
    gas_rho: &mut [f64],
    gas_vel: &mut [[f64; 3]],
    gas_u:   &mut [f64],
    dx: f64,
    dt: f64,
    n:  usize,
    gamma: f64,
    ax: usize, // 0=x, 1=y, 2=z
) {
    if ax == 0 {
        sweep_x(gas_rho, gas_vel, gas_u, dx, dt, n, gamma);
        return;
    }

    // Permute: bring axis ax into position 0
    let n3 = n * n * n;
    let mut p_rho = vec![0.0f64; n3];
    let mut p_vel = vec![[0.0f64; 3]; n3];
    let mut p_u   = vec![0.0f64; n3];

    // Build permuted index: (a, b, c) in permuted space maps to original (i,j,k)
    // ax=1: permuted (a,b,c) → original (b,a,c)
    // ax=2: permuted (a,b,c) → original (c,b,a)  [swap i and k]
    for a in 0..n {
        for b in 0..n {
            for c in 0..n {
                let p_idx = a * n * n + b * n + c;
                let o_idx = match ax {
                    1 => b * n * n + a * n + c,
                    2 => c * n * n + b * n + a,
                    _ => unreachable!(),
                };
                p_rho[p_idx] = gas_rho[o_idx];
                p_u[p_idx]   = gas_u[o_idx];
                // Permute velocity components too
                p_vel[p_idx] = match ax {
                    1 => [gas_vel[o_idx][1], gas_vel[o_idx][0], gas_vel[o_idx][2]],
                    2 => [gas_vel[o_idx][2], gas_vel[o_idx][1], gas_vel[o_idx][0]],
                    _ => unreachable!(),
                };
            }
        }
    }

    sweep_x(&mut p_rho, &mut p_vel, &mut p_u, dx, dt, n, gamma);

    // Permute back
    for a in 0..n {
        for b in 0..n {
            for c in 0..n {
                let p_idx = a * n * n + b * n + c;
                let o_idx = match ax {
                    1 => b * n * n + a * n + c,
                    2 => c * n * n + b * n + a,
                    _ => unreachable!(),
                };
                gas_rho[o_idx] = p_rho[p_idx];
                gas_u[o_idx]   = p_u[p_idx];
                gas_vel[o_idx] = match ax {
                    1 => [p_vel[p_idx][1], p_vel[p_idx][0], p_vel[p_idx][2]],
                    2 => [p_vel[p_idx][2], p_vel[p_idx][1], p_vel[p_idx][0]],
                    _ => unreachable!(),
                };
            }
        }
    }
}
```

```rust
/// Maximum stable hydro timestep: Δt = C_cfl × dx / max(|v| + c_s).
pub fn hydro_cfl(gas_rho: &[f64], gas_vel: &[[f64; 3]], gas_u: &[f64],
                 dx: f64, courant: f64, gamma: f64) -> f64 {
    let v_max = gas_rho.iter().enumerate().map(|(i, &rho)| {
        let p  = (gamma - 1.0) * rho * gas_u[i];
        let cs = (gamma * p / rho.max(1e-30)).sqrt();
        let v  = (gas_vel[i][0].powi(2) + gas_vel[i][1].powi(2) + gas_vel[i][2].powi(2)).sqrt();
        v + cs
    }).fold(0.0_f64, f64::max);
    courant * dx / v_max.max(1e-10)
}

/// Full 3D hydro step: sweep x, then y, then z (Lie-Trotter splitting).
///
/// Also applies gravitational acceleration `grav` as a body-force source term
/// (operator-split after the flux update).
/// If `fifth_force` is `Some(...)`, it is added to the body force as well.
pub fn step(
    gas_rho: &mut [f64],
    gas_vel: &mut [[f64; 3]],
    gas_u:   &mut [f64],
    grav:    &[[f64; 3]],
    fifth_force: Option<&[[f64; 3]]>,
    dx: f64,
    dt: f64,
    n:  usize,
    gamma: f64,
) {
    sweep_axis(gas_rho, gas_vel, gas_u, dx, dt, n, gamma, 0);
    sweep_axis(gas_rho, gas_vel, gas_u, dx, dt, n, gamma, 1);
    sweep_axis(gas_rho, gas_vel, gas_u, dx, dt, n, gamma, 2);

    // Gravity + fifth-force body force: operator-split kick on gas velocity and energy.
    // Δ(ρv) = ρ g Δt   →   Δv = g Δt
    // ΔE    = ρ v·g Δt  →   Δu = v_mid·g Δt  (using post-flux velocity for simplicity)
    for idx in 0..gas_rho.len() {
        let mut acc = grav[idx];
        if let Some(ff) = fifth_force {
            acc[0] += ff[idx][0];
            acc[1] += ff[idx][1];
            acc[2] += ff[idx][2];
        }
        let v_old = gas_vel[idx];
        gas_vel[idx][0] += acc[0] * dt;
        gas_vel[idx][1] += acc[1] * dt;
        gas_vel[idx][2] += acc[2] * dt;
        // Update internal energy: ΔE = ρ v·a dt → Δu = v_mid·a dt
        let v_mid = [
            0.5 * (v_old[0] + gas_vel[idx][0]),
            0.5 * (v_old[1] + gas_vel[idx][1]),
            0.5 * (v_old[2] + gas_vel[idx][2]),
        ];
        gas_u[idx] += v_mid[0]*acc[0]*dt + v_mid[1]*acc[1]*dt + v_mid[2]*acc[2]*dt;
        gas_u[idx] = gas_u[idx].max(1e-30);
    }
}
```

```rust
    }
}
```

## Task 8: Radiative cooling

**Files:**
- Create: `src/hydro/cooling.rs`

Cooling is operator-split: after the Godunov step, integrate du/dt = −Λ(T)n²/(ρ) for each cell independently.

The cooling function uses a simple two-regime approximation for primordial H/He:
- T < 10⁴ K: Λ = 0 (floor, photoionised)
- 10⁴ ≤ T < 10⁵ K: Λ = 10⁻²² × (T/10⁴)⁰·⁵ erg cm³/s (line cooling)
- T ≥ 10⁵ K: Λ = 10⁻²³ × (T/10⁵)⁰·⁵ erg cm³/s (bremsstrahlung)

Unit conversion from Λ [erg cm³/s] to code [km²/s² per τ]:
```
Λ_code = Λ × n_H_code² × dt_code / (ρ_code × unit_conversion_factors)
```
where n_H ≈ X ρ / m_p (X=0.76 hydrogen mass fraction).

- [ ] **Write failing tests for cooling**

Create `src/hydro/cooling.rs`:
```rust
//! Radiative cooling via operator splitting.
//!
//! Cooling rate Λ(T): simple two-power-law fit to primordial H/He cooling
//! (Sutherland & Dopita 1993). Operator-split from hydro: each cell
//! integrated independently over dt.

use crate::utils::types::Real;
use crate::hydro::ic::{u_from_temperature, temperature_from_u};

/// Cooling rate Λ(T) in units of erg cm³/s (normalised to n_H²).
/// Returns 0 below T_floor (photoionisation equilibrium assumption).
pub fn lambda_cooling(t_k: Real) -> Real {
    const T_FLOOR: Real = 1.0e4;  // K
    const T_BREAK: Real = 1.0e5;  // K
    if t_k < T_FLOOR { return 0.0; }
    if t_k < T_BREAK {
        1.0e-22 * (t_k / T_FLOOR).powf(0.5)
    } else {
        1.0e-23 * (t_k / T_BREAK).powf(0.5)
    }
}

/// Unit conversion: erg cm³/s → (km/s)² × (Mpc/h)³/M_sun × s⁻¹
/// Accounts for n_H² / ρ factor.
///
/// du/dt = −Λ(T) × n_H² / ρ  [erg/g/s]
///       = −Λ(T) × (X/m_p)² × ρ  [erg/g/s]
///
/// Conversion: 1 erg/g = 10⁻¹⁰ (km/s)²
/// n_H = X ρ_phys / m_p,  X=0.76,  m_p = 1.673e-24 g
/// ρ_phys = gas_rho × ρ̄_matter,  ρ̄_matter in code units → g/cm³:
///   ρ̄_matter_cgs = 2.775e11 × Ω_m × h² M_sun/Mpc³ × (M_sun_cgs/Mpc_cm³)
///   = 2.775e11 × Ω_m × h² × 1.989e33 / (3.086e24)³ g/cm³
///   ≈ 9.47e-30 × Ω_m × h² g/cm³  (for Ω_m=0.3, h=0.67: ≈ 1.28e-30 g/cm³)
///
/// Full pre-factor baked into `cooling_prefactor(omega_m, h)`.
pub fn cooling_prefactor(omega_m: Real, h: Real) -> Real {
    const X_H: Real = 0.76;        // hydrogen mass fraction
    const M_P: Real = 1.673e-24;   // g
    const ERG_TO_KMS2: Real = 1e-10; // erg/g → (km/s)²
    // ρ̄_matter in g/cm³
    let rho_bar_cgs = 9.47e-30 * omega_m * h * h;
    // du/dt = -Λ × (X/m_p)² × ρ_code × ρ̄_cgs × ERG_TO_KMS2
    // pre = (X/m_p)² × ρ̄_cgs × ERG_TO_KMS2  [cm³ (km/s)² / (erg s)]
    // then du/dt [km/s²/code_unit_time] = -Λ_cgs × pre × gas_rho × dt_seconds
    (X_H / M_P).powi(2) * rho_bar_cgs * ERG_TO_KMS2
}

/// Seconds per supercomoving time unit (approximate: H₀ = 100 h km/s/Mpc).
///
/// dτ is conformal time in units where H₀=100 km/s/(Mpc/h).
/// 1 Mpc/h / (km/s) = 3.086e22 m / (1e3 m/s) = 3.086e19 s → 1 τ ≈ 3.086e19 / h s
pub fn tau_to_seconds(h: Real) -> Real {
    3.086e19 / h
}

/// Apply radiative cooling to a single cell for timestep dt [τ].
///
/// Returns new specific internal energy u (floored at u_floor = u(T_floor)).
pub fn cool_cell(
    gas_rho: Real,
    u: Real,
    dt: Real,
    omega_m: Real,
    h: Real,
) -> Real {
    let t_k = temperature_from_u(u);
    let lam = lambda_cooling(t_k);
    if lam == 0.0 { return u; }

    let pre   = cooling_prefactor(omega_m, h);
    let dt_s  = dt * tau_to_seconds(h);
    // du = -Λ × pre × ρ_code × dt_s
    let du    = lam * pre * gas_rho * dt_s;
    let u_new = u - du;

    // Floor at T=10^4 K
    u_new.max(u_from_temperature(1.0e4))
}

/// Apply cooling to the full gas grid.
pub fn cooling_step(
    gas_rho: &[Real],
    gas_u:   &mut [Real],
    dt:      Real,
    omega_m: Real,
    h:       Real,
) {
    for i in 0..gas_rho.len() {
        gas_u[i] = cool_cell(gas_rho[i], gas_u[i], dt, omega_m, h);
    }
}
```

```rust
//! Stochastic star formation following Schmidt (1959) + Katz (1992).
//!
//! Cells denser than ρ_SF and cooler than T_SF spawn star particles with
//! probability p = 1 − exp(−ε_SF × Δt / t_ff).

use crate::utils::types::Real;
use crate::hydro::ic::temperature_from_u;
use crate::simulation::StarParticle;

/// Free-fall time t_ff = √(3π / (32 G ρ_phys)) [seconds].
///
/// In code units: ρ_phys = gas_rho × ρ̄_matter_cgs.
/// G_cgs = 6.674e-8 cm³/(g s²).
fn free_fall_time_s(gas_rho: Real, omega_m: Real, h: Real) -> Real {
    let rho_bar_cgs = 9.47e-30 * omega_m * h * h;
    let rho_cgs = gas_rho * rho_bar_cgs;
    let g_cgs = 6.674e-8_f64;
    (3.0 * std::f64::consts::PI / (32.0 * g_cgs * rho_cgs)).sqrt()
}

/// Convert number density threshold from H/cm³ to code units (ρ_gas / ρ̄_matter).
pub fn rho_sf_code(rho_sf_h_cm3: Real, omega_m: Real, h: Real) -> Real {
    let rho_bar_cgs = 9.47e-30 * omega_m * h * h;
    let m_p_cgs     = 1.673e-24_f64;
    // ρ_SF_cgs = rho_sf_h_cm3 × m_p
    let rho_sf_cgs  = rho_sf_h_cm3 * m_p_cgs;
    rho_sf_cgs / rho_bar_cgs
}

/// Attempt to form stars in every eligible cell.
///
/// Returns the list of newly created star particles.
/// Eligible cells: gas_rho > rho_sf_code AND T < t_sf_thresh.
/// Probability: p = 1 − exp(−eps_sf × Δt_s / t_ff_s).
///
/// Uses a deterministic pseudo-random check seeded by cell index + step
/// to avoid introducing an RNG state. (Real runs should use a proper RNG;
/// this is sufficient for reproduction.)
pub fn form_stars(
    gas_rho: &mut [Real],
    gas_vel: &[[Real; 3]],
    gas_u:   &[Real],
    cell_positions: &[[Real; 3]],  // cell centre positions
    m_cell: Real,          // mass of one cell = m_part equivalent
    rho_sf: Real,          // SF density threshold in code units
    t_sf:   Real,          // SF temperature threshold [K]
    eps_sf: Real,          // SF efficiency
    dt:     Real,          // timestep [τ]
    omega_m: Real,
    h: Real,
    step_id: u64,
) -> Vec<StarParticle> {
    let tau_to_s = 3.086e19 / h;
    let dt_s = dt * tau_to_s;
    let mut new_stars = Vec::new();

    for i in 0..gas_rho.len() {
        if gas_rho[i] < rho_sf { continue; }
        let t_k = temperature_from_u(gas_u[i]);
        if t_k > t_sf { continue; }

        let t_ff = free_fall_time_s(gas_rho[i], omega_m, h);
        let prob = 1.0 - (-eps_sf * dt_s / t_ff).exp();

        // Deterministic pseudo-random: hash cell index and step
        let hash = ((i as u64).wrapping_mul(2654435761) ^ step_id.wrapping_mul(2246822519)) as f64
                   / u64::MAX as f64;
        if hash < prob {
            let star_mass = gas_rho[i] * m_cell * 0.5; // form 50% of cell mass into stars
            gas_rho[i] *= 0.5; // remove mass from cell

            new_stars.push(StarParticle {
                pos:   cell_positions[i],
                vel:   gas_vel[i],
                mass:  star_mass,
                age_a: 0.0, // filled in by caller with current scale factor
            });
        }
    }
    new_stars
}
```

```rust
//! Supernova thermal feedback.
//!
//! After delay t_delay, each star particle deposits thermal energy
//! E_SN = eps_sn × M_star × c² into the surrounding 27 cells
//! with a Gaussian kernel.

use crate::utils::types::Real;
use crate::simulation::StarParticle;

/// Speed of light [km/s].
const C_KMS: Real = 299_792.458;

/// Deposit SN energy from mature star particles into the gas internal energy grid.
///
/// A star particle is "mature" when (a_current - star.age_a) × t_hubble_myr > t_delay_myr.
/// Mature particles are consumed (removed from the list).
///
/// `t_hubble_myr` ≈ 977.8 / h  Myr (Hubble time at z=0 in Myr).
/// The delay is approximate: we use Δa rather than proper time for simplicity.
pub fn supernova_feedback(
    star_particles: &mut Vec<StarParticle>,
    gas_u:          &mut [Real],
    a_current:      Real,
    h:              Real,
    eps_sn:         Real,
    t_delay_myr:    Real,
    n:              usize,
    dx:             Real,
    box_size:       Real,
) {
    // Δa threshold corresponding to t_delay_myr (rough: Δa ≈ H(a)×Δt ≈ a×H₀×Δt for matter domination)
    // For simplicity: use H₀ = 100h km/s/Mpc → t_H0 = 977.8/h Gyr = 977800/h Myr
    let t_hubble_myr = 977_800.0 / h;
    let da_threshold = t_delay_myr / t_hubble_myr; // very rough but sufficient

    let mut remaining = Vec::new();
    let n2 = n * n;

    for star in star_particles.drain(..) {
        if a_current - star.age_a < da_threshold {
            remaining.push(star);
            continue;
        }
        // Energy to deposit: E_SN = eps_sn × M × c²  [(km/s)² × M_sun/h code mass]
        // gas_u is in (km/s)², gas_rho is dimensionless (ρ/ρ̄).
        // Δu per cell = E_SN / (27 × M_cell), with Gaussian weights summing to 27.
        let e_sn = eps_sn * star.mass * C_KMS * C_KMS;

        // Find the grid cell containing this star
        let ci = ((star.pos[0] / box_size * n as Real) as usize).min(n - 1);
        let cj = ((star.pos[1] / box_size * n as Real) as usize).min(n - 1);
        let ck = ((star.pos[2] / box_size * n as Real) as usize).min(n - 1);

        // Deposit into 3×3×3 neighbourhood with equal weighting (Gaussian approx)
        let weight = 1.0 / 27.0;
        for di in 0..3_usize {
            for dj in 0..3_usize {
                for dk in 0..3_usize {
                    let ii = (ci + di + n - 1) % n;
                    let jj = (cj + dj + n - 1) % n;
                    let kk = (ck + dk + n - 1) % n;
                    let idx = ii * n2 + jj * n + kk;
                    // Δu = E_SN × weight / M_cell; M_cell ≈ star.mass (same particle mass)
                    // Since gas_u is specific energy, add e_sn/M_cell per unit gas mass:
                    // Δu_specific = e_sn × weight / (gas_rho × cell_volume × rho_bar)
                    // For simplicity add to u directly normalised per star mass
                    gas_u[idx] += e_sn * weight / (star.mass.max(1e-30));
                }
            }
        }
        // Don't add back to remaining — star is consumed by SN
    }

    *star_particles = remaining;
}
```

```rust
//! Friends-of-Friends halo finder and stacked radial profile output.
//!
//! FoF linking length: b = 0.2 × mean inter-particle spacing.
//! Profile bins: 20 log-spaced bins from 0.1 to 3.0 × R_200.
//! Output: `halo_profiles_{idx:04}.txt` with columns:
//!   r/R200  rho_gas/rho_mean  T_K  rho_dm/rho_mean  N_halos

use crate::utils::types::Real;

// ── FoF ──────────────────────────────────────────────────────────────────────

/// Find FoF groups in the particle set.
///
/// Returns a `Vec<Vec<usize>>` — each inner vec is the particle indices of one group.
/// `b` is the linking length [Mpc/h].
/// Uses union-find for efficiency (O(N α(N)) ≈ O(N)).
pub fn friends_of_friends(pos: &[[Real; 3]], b: Real) -> Vec<Vec<usize>> {
    let n = pos.len();
    let mut parent: Vec<usize> = (0..n).collect();

    fn find(parent: &mut Vec<usize>, mut x: usize) -> usize {
        while parent[x] != x {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        x
    }

    let b2 = b * b;
    for i in 0..n {
        for j in (i + 1)..n {
            let dx = pos[i][0] - pos[j][0];
            let dy = pos[i][1] - pos[j][1];
            let dz = pos[i][2] - pos[j][2];
            if dx*dx + dy*dy + dz*dz < b2 {
                let ri = find(&mut parent, i);
                let rj = find(&mut parent, j);
                if ri != rj { parent[ri] = rj; }
            }
        }
    }

    // Collect groups
    let mut groups: std::collections::HashMap<usize, Vec<usize>> = Default::default();
    for i in 0..n {
        groups.entry(find(&mut parent, i)).or_default().push(i);
    }
    groups.into_values().collect()
}

/// Centre-of-mass position of a particle group.
pub fn group_centre(pos: &[[Real; 3]], members: &[usize]) -> [Real; 3] {
    let mut c = [0.0f64; 3];
    for &i in members {
        c[0] += pos[i][0];
        c[1] += pos[i][1];
        c[2] += pos[i][2];
    }
    let n = members.len() as Real;
    [c[0]/n, c[1]/n, c[2]/n]
}

/// R_200: radius enclosing mean density = 200 × ρ_crit.
/// Approximate: from the virial mass M = (4π/3) × 200 ρ_crit R_200³.
/// ρ_crit in code units: ρ_crit = 3H²/(8πG), with H=H₀=100h [km/s/Mpc] → ρ_crit/ρ̄ = 1/Ω_m.
pub fn r200(n_members: usize, m_part: Real, omega_m: Real) -> Real {
    // M_halo = n_members × m_part [M_sun/h]
    // R_200 = (3 M / (4π × 200 × ρ_crit))^{1/3}
    // ρ_crit/ρ̄_m = 1/Ω_m  → ρ_crit = ρ̄_m / Ω_m  (at z=0 in code units ρ̄_m=1)
    // ρ_crit code = 2.775e11 h² M_sun/Mpc³  (but we work in Mpc/h so h drops out)
    // For simplicity work in units where ρ̄_matter = 1:
    //   ρ_crit = 1.0 / omega_m
    //   M in units = n_members  (each particle has mass 1 in units of m_mean per particle)
    // This gives a dimensionless R_200; multiply by box_size/n_part for physical units.
    // Better: pass m_part in M_sun/h and box_size so we can compute absolute R_200.
    // Here we return R_200 in Mpc/h assuming m_part is in M_sun/h.
    //   ρ_crit = 2.775e11 × h² M_sun/(Mpc/h)³  → use h=0.67: 1.246e11 M_sun/(Mpc/h)³
    //   But we don't have h here. Leave as a function of m_part and omega_m.
    //   ρ_crit ≈ 2.775e11 × 0.67² / omega_m × omega_m  M_sun / (Mpc/h)³
    //           = 2.775e11 × 0.4489  M_sun / (Mpc/h)³ = 1.246e11
    let rho_crit = 1.246e11_f64; // M_sun/(Mpc/h)³ for h=0.67 (hardcoded; pass as param in future)
    let m_halo = n_members as Real * m_part;
    (3.0 * m_halo / (4.0 * std::f64::consts::PI * 200.0 * rho_crit)).powf(1.0 / 3.0)
}

// ── Stacked profiles ─────────────────────────────────────────────────────────

const N_BINS: usize = 20;
const R_MIN_FRAC: Real = 0.1;  // in units of R_200
const R_MAX_FRAC: Real = 3.0;

/// Compute stacked radial profiles for halos in a given mass range.
///
/// Returns arrays of length N_BINS: (r_mid/R200, rho_gas_stack, T_stack, rho_dm_stack, counts).
#[allow(clippy::too_many_arguments)]
pub fn stacked_profiles(
    dm_pos:   &[[Real; 3]],
    gas_rho:  &[Real],
    gas_u:    &[Real],
    n_grid:   usize,
    box_size: Real,
    m_part:   Real,
    omega_m:  Real,
    m_min:    Real, // M_sun/h
    m_max:    Real, // M_sun/h
    groups:   &[Vec<usize>],
) -> ([Real; N_BINS], [Real; N_BINS], [Real; N_BINS], [Real; N_BINS], [usize; N_BINS], usize) {
    let dx = box_size / n_grid as Real;
    let gamma = 5.0_f64 / 3.0;

    // Temperature from u: T = u / KB_OVER_MU_MP
    let u_to_t = 1.0 / (0.008314 / 0.59);

    // Log-spaced bin edges
    let log_rmin = R_MIN_FRAC.ln();
    let log_rmax = R_MAX_FRAC.ln();
    let dlog = (log_rmax - log_rmin) / N_BINS as Real;

    let mut rho_gas_sum = [0.0f64; N_BINS];
    let mut t_sum       = [0.0f64; N_BINS];
    let mut rho_dm_sum  = [0.0f64; N_BINS];
    let mut counts      = [0usize; N_BINS];
    let mut n_halos     = 0usize;

    for group in groups {
        let m_halo = group.len() as Real * m_part;
        if m_halo < m_min || m_halo > m_max { continue; }
        n_halos += 1;

        let centre = group_centre(dm_pos, group);
        let r200_h = r200(group.len(), m_part, omega_m);

        // For each bin, accumulate gas and DM contributions
        // DM: count particles in each radial bin, normalise to mean DM density
        let mut dm_bin_counts = [0usize; N_BINS];
        for &i in group {
            let dr = [
                dm_pos[i][0] - centre[0],
                dm_pos[i][1] - centre[1],
                dm_pos[i][2] - centre[2],
            ];
            let r = (dr[0]*dr[0] + dr[1]*dr[1] + dr[2]*dr[2]).sqrt() / r200_h;
            if r < R_MIN_FRAC || r >= R_MAX_FRAC { continue; }
            let bin = ((r.ln() - log_rmin) / dlog) as usize;
            if bin < N_BINS { dm_bin_counts[bin] += 1; }
        }

        // Gas: loop over a cube of cells around the halo centre
        let r_max_phys = R_MAX_FRAC * r200_h;
        let cells_per_side = (2.0 * r_max_phys / dx).ceil() as usize + 2;
        let ci0 = ((centre[0] / dx) as isize).saturating_sub(cells_per_side as isize / 2);
        let cj0 = ((centre[1] / dx) as isize).saturating_sub(cells_per_side as isize / 2);
        let ck0 = ((centre[2] / dx) as isize).saturating_sub(cells_per_side as isize / 2);

        for di in 0..cells_per_side {
            for dj in 0..cells_per_side {
                for dk in 0..cells_per_side {
                    let ci = ((ci0 + di as isize).rem_euclid(n_grid as isize)) as usize;
                    let cj = ((cj0 + dj as isize).rem_euclid(n_grid as isize)) as usize;
                    let ck = ((ck0 + dk as isize).rem_euclid(n_grid as isize)) as usize;
                    let cell_pos = [
                        (ci as Real + 0.5) * dx,
                        (cj as Real + 0.5) * dx,
                        (ck as Real + 0.5) * dx,
                    ];
                    let dr = [
                        cell_pos[0] - centre[0],
                        cell_pos[1] - centre[1],
                        cell_pos[2] - centre[2],
                    ];
                    let r = (dr[0]*dr[0] + dr[1]*dr[1] + dr[2]*dr[2]).sqrt() / r200_h;
                    if r < R_MIN_FRAC || r >= R_MAX_FRAC { continue; }
                    let bin = ((r.ln() - log_rmin) / dlog) as usize;
                    if bin >= N_BINS { continue; }

                    let idx = ci * n_grid * n_grid + cj * n_grid + ck;
                    rho_gas_sum[bin] += gas_rho[idx];
                    t_sum[bin]       += gas_u[idx] * u_to_t;
                    counts[bin]      += 1;
                }
            }
        }

        for bin in 0..N_BINS {
            rho_dm_sum[bin] += dm_bin_counts[bin] as Real;
        }
    }

    // Normalise
    let mut r_mid   = [0.0f64; N_BINS];
    let mut rho_gas = [0.0f64; N_BINS];
    let mut t_mean  = [0.0f64; N_BINS];
    let mut rho_dm  = [0.0f64; N_BINS];
    for bin in 0..N_BINS {
        r_mid[bin] = (log_rmin + (bin as Real + 0.5) * dlog).exp();
        if counts[bin] > 0 {
            rho_gas[bin] = rho_gas_sum[bin] / counts[bin] as Real;
            t_mean[bin]  = t_sum[bin]       / counts[bin] as Real;
            rho_dm[bin]  = rho_dm_sum[bin]  / counts[bin] as Real / n_halos.max(1) as Real;
        }
    }

    (r_mid, rho_gas, t_mean, rho_dm, counts, n_halos)  // 6-tuple: r, rho_gas, T, rho_dm, counts, n_halos
}

/// Write profiles to a text file.
pub fn write_profiles(path: &str, r_mid: &[Real; N_BINS], rho_gas: &[Real; N_BINS],
                      t_k: &[Real; N_BINS], rho_dm: &[Real; N_BINS],
                      counts: &[usize; N_BINS], n_halos: usize, mass_label: &str) {
    use std::io::Write;
    let mut f = std::fs::File::create(path).expect("Cannot create profile file");
    writeln!(f, "# mass_bin={mass_label}  n_halos={n_halos}").unwrap();
    writeln!(f, "# r/R200  rho_gas/rho_mean  T_K  rho_dm/rho_mean  N_cells").unwrap();
    for i in 0..N_BINS {
        writeln!(f, "{:.4e} {:.4e} {:.4e} {:.4e} {}",
                 r_mid[i], rho_gas[i], t_k[i], rho_dm[i], counts[i]).unwrap();
    }
}
```
